Method

How a claim becomes a file

Arı Kaynak exists because most viral health content is compressed past the point of being accurate. Here's exactly how we check it.

1. We start with the claim, not the conclusion

Every file begins with something that's actually circulating — a video, a post, a headline — quoted as closely as fair use allows, so you can see exactly what was said before we say anything about it.

2. We find the original source

We trace the claim back to the underlying study, trial, or dataset — not to another article that cited it. If we can't find a credible primary source, we say so in the file instead of filling the gap with plausible-sounding text.

3. We compare, not just summarize

Each file separates what the research actually supports from what got added in translation — a stronger verb, a dropped caveat, an animal result presented as a human one. That gap is the whole point of the file.

4. Every file gets a stamp

Supported, Mostly Supported, Partly Supported, Misleading, or Unsupported. The stamp evaluates the exact wording of the claim against the exact finding of the source — not whether the underlying science or topic is legitimate. A claim can come from a strong study and still be stamped Mostly Supported if the claim's own phrasing (a stronger verb, an absolute like "no matter what" or "proven") reaches slightly further than what was actually measured.

5. We show our evidence grading, not just our conclusion

Every file lists an evidence type (randomized controlled trial, cohort study, meta-analysis, animal study, position statement, etc.) and an evidence strength rating:

  • Strong — large, well-controlled studies, systematic reviews, or expert-consensus position statements with graded evidence.
  • Moderate — a single well-run trial or cohort study, not yet replicated at scale.
  • Limited — early-stage evidence, animal studies extrapolated to humans, or associations without a clear causal mechanism.

These ratings describe the source we cite, not our confidence in our own writing. We don't upgrade a rating because a finding is convenient or interesting.

6. When the evidence is weak, we say so

If a claim traces back to a single small study, an animal model, or a preprint that hasn't been peer-reviewed, the file says that explicitly rather than presenting it with the same confidence as a large randomized trial. If we can't find a credible primary source at all, we don't publish a verdict — we publish that gap.

Who's behind this

Arı Kaynak is an independently run publication. It is not affiliated with any pharmaceutical, supplement, or wellness brand, and does not accept payment in exchange for a specific verdict.

Corrections

If you believe a file misrepresents a source, mislabels a study type, or contains an error, you can open an issue on our public GitHub repository. Substantive corrections are noted directly on the affected file rather than removed quietly.
